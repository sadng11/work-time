# work_time — سامانه ثبت ساعت کاری

کاربردهای زمانی و پروژه‌ای برای **ثبت ساعات کاری** و گزارش مالی.  
پروژه به زبان **فارسی** طراحی شده است: تاریخ/زمان جلالی، پول فارسی، متون فارسی و …

## ساختار

```
work_time/
├── settings.py          # تنظیمات (JALALI=True, TIME_ZONE='Asia/Tehran')
├── model.py             # BaseModel با created_at / updated_at
└── urls.py              # URL پروژه
```

### مدل‌ها (`timesheet/models.py`)

| مدل | توضیح |
|------|-------|
| **Project** | نام پروژه، کاربر مسئول، کارفرما (employer) و قیمت واحد. |
| **TimeEntry** | ورودی ساعت کاری — زمان شروع/پایان، مدت و توضیحات. |

- `TimeEntry` در هنگام ذخیره به‌طور خودکار `duration = exit_time - entry_time` را محاسبه می‌کند.
- `cal_duration` مدت را به فرمت فارسی (`X روز Y ساعت Z دقیقه`) برگرداند.

### ویوها (`timesheet/views.py`)

| ویو | توضیح |
|------|-------|
| **home** | ثبت ورودی جدید — اگر آخرین رکورد باز است، زمان خروج را آپدیت می‌کند وگرنه رکورد جدید می‌سازد. |
| **report** | گزارش روزانه با فیلتر تاریخ / پروژه + مجموع مدت هر روز. |
| **factor** | محاسبه هزینه پایه × ساعت کل → مبلغ نهایی + شماره فاکتور (با `num2fawords`). |

### فرم‌ها (`timesheet/forms.py`)

- **TimeEntryForm**: مدل فرم ثبت ورودی با `entry_time`.
